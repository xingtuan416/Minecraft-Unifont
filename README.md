# Minecraft Unifont

Minecraft 中文像素字体，由 GNU Unifont 16.0.03 的 16x16 字模转换为 TTF。中文、英文与符号均来自 Unifont。

## 下载

- [Minecraft-Unifont.ttf](https://github.com/xingtuan416/Minecraft-Unifont/releases/latest/download/Minecraft-Unifont.ttf)

## 字体信息

- 家族名：Minecraft Unifont
- 30,767 字形
- 覆盖：CJK 基本区、扩展 A、兼容区、中文标点、假名、全角、Latin-1、ASCII
- 不含 CJK 扩展 B 与 emoji
- 建议 16 / 32 / 64px

## 安装

Windows 右键安装；macOS 打开字体册；Linux 复制到 ~/.local/share/fonts 后运行 fc-cache -f。
